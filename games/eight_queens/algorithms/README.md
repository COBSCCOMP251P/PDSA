# Eight Queens Algorithms

This directory contains the algorithm implementations for the Eight Queens problem.

## Required Algorithms
1. **Recursive Backtracking** - Main solution approach
2. **Optimization Technique** - Heuristic or pruning method

## Files to Implement
- `backtracking_solver.py` - Core recursive backtracking algorithm
- `optimized_solver.py` - Enhanced version with optimizations
- `performance_analyzer.py` - Algorithm performance comparison

## Getting Started
```python
from algorithms.backtracking_solver import EightQueensBacktracking

solver = EightQueensBacktracking()
solutions = solver.solve()
```
