# Snake and Ladder Game Module

**Developer:** Member 1  
**Game:** Snake and Ladder Problem  
**Assignment:** PDSA Interactive Algorithm Games

## 🎯 Problem Description
Find the minimum number of dice throws required to reach the end of a randomly generated Snake & Ladder board.

## 🧠 Algorithm Requirements
- **Algorithm 1**: BFS (Breadth-First Search)
- **Algorithm 2**: Dynamic Programming
- **Board Size**: N×N (6 ≤ N ≤ 12)
- **Snakes & Ladders**: N-2 each, randomly positioned

## 📁 Module Structure
```
snake_ladder/

├── frontend/        # Game board visualization  
├── api/            # FastAPI endpoints
├── tests/          # Unit tests

```
