# Tower of Hanoi Game Module

**Developer:** Member 4  
**Game:** Tower of Hanoi Problem  
**Assignment:** PDSA Interactive Algorithm Games

## 🎯 Problem Description
Solve the Tower of Hanoi puzzle with 3 or 4 pegs using different algorithmic approaches.

## 🧠 Algorithm Requirements
- **3-Peg Algorithms**: Recursive + Iterative
- **4-Peg Algorithms**: Frame-Stewart + Recursive
- **Disks**: Random count (5-10 disks)
- **Pegs**: User choice (3 or 4 pegs)

## 📁 Module Structure
```
tower_hanoi/
├── algorithms/       # Multiple Hanoi algorithms
├── frontend/        # Tower visualization and moves
├── api/            # FastAPI endpoints
├── tests/          # Unit tests
└── docs/           # Analysis and reports
```

## 🚀 Getting Started
1. Implement 4 different algorithms in `algorithms/`
2. Create tower visualization in `frontend/`
3. Set up API endpoints in `api/`
4. Write comprehensive tests
5. Compare 3-peg vs 4-peg approaches

## 📊 Expected Deliverables
- Optimal moves calculation
- Move sequence generation
- Interactive tower visualization
- Algorithm comparison (3 vs 4 pegs)
- Performance analysis
