About Tower of Hanoi

The Puzzle

The Tower of Hanoi is a classic mathematical puzzle invented by French mathematician Édouard Lucas in 1883. The objective is to move all disks from one peg to another, following these simple rules:

  • Only one disk can be moved at a time
  • Only the top disk from a peg can be moved
  • A larger disk cannot be placed on a smaller disk

Algorithms

This application implements and benchmarks four different solving algorithms:

  • Recursive 3-Peg: Classic recursive solution (2^n - 1 moves)
  • Iterative 3-Peg: Stack-based iterative approach
  • Frame-Stewart 4-Peg: Optimal algorithm for 4 pegs
  • Dynamic Programming 4-Peg: DP approach with memoization

Technology

Built with modern web technologies:

  • Frontend: HTML5, CSS3, Vanilla JavaScript
  • Backend: Python FastAPI
  • Database: MySQL
  • Visualization: Chart.js

Educational Value

This project demonstrates key computer science concepts:

  • Recursive algorithms and data structures
  • Algorithm complexity analysis
  • Dynamic programming optimization
  • Performance benchmarking and comparison
