# Traffic Simulation Game Module

**Developer:** Member 2  
**Game:** Traffic Simulation Problem  
**Assignment:** PDSA Interactive Algorithm Games

## 🎯 Problem Description
Calculate maximum flow through a traffic network with randomly assigned road capacities.

## 🧠 Algorithm Requirements
- **Algorithm 1**: Ford-Fulkerson Algorithm
- **Algorithm 2**: Edmonds-Karp Algorithm  
- **Network**: Nodes A→T with random capacities (5-15 vehicles/min)
- **Visualization**: Traffic network graph display

## 📁 Module Structure
```
traffic_simulation/
├── algorithms/       # Flow algorithms
├── frontend/        # Network graph visualization
├── api/            # FastAPI endpoints

```
